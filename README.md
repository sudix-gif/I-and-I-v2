# I&I Social Media v2

A simple social media platform built with:

- Node.js
- Express
- HTML
- CSS
- JavaScript
- Multer

## Features

- User Registration
- Login
- Text Posts
- Photo Upload
- Video Upload
- Audio Upload
- Likes
- Comments
- Topics
- Admin Dashboard
- User Management
- Statistics

## Installation

```bash
npm install
node app.js
```

Open:

http://localhost:3000

## Version

v2.0.0
